# ServicenowGamification
AI-powered Service Desk platform integrated with ServiceNow to analyze agent performance, gamify achievements, predict SLA breaches using ML, and provide LLM-driven recommendations. It improves agent engagement, service quality, first-call resolution, SLA compliance, and overall operational efficiency. 

Find the below steps 

Step 1: Create the template.py
        here, creatigng the required folder and files 
Step 2: Creating the setup.py
        here,about project and author details
Step 3: Create the requirments.txt
        here,installing the required Python,ML and AI Libraries
Step 4: Create Config-> Config.yaml 
        here,Configuring variables for each and every Modules like DataIngestion,etc 
Step 5: Create params.yaml
        here,Configuring the all parameters variable for all modules  
Step 6: Create the Constant ->__init__.py 
        here,Stores the paths for Config.yaml and params.yaml  
Step 7: Create Entity-> Config_Entity 
        here, Snapchat of Config.yaml 
Step 8: Create src->Utils->Common.py
        here,Creating the folder for all modules and etc  
              
Step 9: Repeat the Below steps 
    1) Update config.yaml
    2) Update params.yaml
    3) Update entity
    4) update the Configuration Manager in src config
    5) Update the Components
    6) Update the Pipeline
    7) Update the Main.py
